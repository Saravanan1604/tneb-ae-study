# TNEB AE (EEE) Study Site

A study website built from the TNEB AE (EEE) Complete Book and Question Book: every topic's chapter notes,
formulas, all 2,620 past questions with full solutions, GATE sums, a mock test and a progress console.

Open it at **https://saravanan1604.github.io/tneb-ae-study/**

Static files only (no build step): `index.html`, `app.js`, `data/` (topic data) and `img/` (book pictures).
Progress is kept in the browser you use.
